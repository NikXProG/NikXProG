### 🚀 Projects

#### 🌊 [Inktide](https://github.com/inktide-ai/inktide)
AI companion for live streams. It reads Discord, Twitch and Telegram chat and answers in voice. TTS starts on the first sentence while the LLM is still writing the rest, so there's no pause between thinking and speaking.

`.NET 10` · `Next.js` · `Rust` · `Python` · `Redis Streams` · `SignalR` · `Keycloak` · `Qdrant`

#### 🐀 [Babrat](https://github.com/NikXProG/babrat-engine)
Embedded relational database engine in C++20. It has its own SQL parser, a rule-based optimizer, Volcano-style execution, MVCC transactions, WAL with checkpointing and B-Tree storage. It speaks the PostgreSQL wire protocol, so you can connect with a regular `psql`.

`C++20` · `CMake` · `Docker`

#### 📍 [AdPlatformStorage](https://github.com/NikXProG/AdPlatformStorage)
REST API that finds advertising platforms for a region, including platforms of all its parent regions. Data lives in an in-memory trie, so lookup time depends only on the path length, not on how many platforms are stored.

`.NET 9` · `ASP.NET Core` · `Docker`

#### 🧩 [CustomLang](https://github.com/NikXProG/CustomLang)
Interpreter for a custom programming language. Parser combinators build an AST that visitors evaluate. It supports functions and imports, and keywords are configured through an INI file.

`C#` · `.NET 9` · `Sprache`
